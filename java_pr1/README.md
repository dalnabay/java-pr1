## Задача работы

В этой работе разобраны массивы, циклы и методы. Подготовлены пять небольших программ: каждая решает свое задание и запускается отдельно.

## Выполненные задания

### Обработка готового массива

В `Main` задан массив из пяти чисел: `7, 14, 21, 28, 35`. Цикл `for` перебирает его элементы и накапливает сумму в переменной `total`. Среднее вычисляется делением суммы на длину массива. Приведение к `double` сохраняет дробную часть результата.

Для этого примера сумма равна `105`, среднее значение равно `21`. При выводе среднее форматируется с двумя знаками после разделителя.

### Ввод массива и поиск крайних значений

`ArrayInput` читает количество элементов и сами числа через `Scanner`. При нулевом или отрицательном размере программа выводит сообщение и заканчивает работу.

Для вычисления суммы написаны два метода: `sumWithWhile()` и `sumWithDoWhile()`. Они получают один и тот же массив, но используют разные циклы. Это позволяет сравнить результаты двух способов обхода. Минимум и максимум находятся отдельным циклом с обычными проверками `if`.

Например, для чисел `9, -2, 5, 0` сумма равна `12`, минимум равен `-2`, максимум равен `9`. В начале поиска минимум и максимум берутся из первого элемента, поэтому алгоритм работает и для массива только из отрицательных чисел.

### Аргументы запуска

`CommandLineArguments` выводит строки из массива `args` через цикл `for`. Это данные, переданные программе при запуске из командной строки. Если аргументов нет, выводить нечего.

### Гармонический ряд

`HarmonicSeries` перебирает знаменатели от `1` до `10` и вычисляет значение `1.0 / denominator`. Программа выводит номер члена, дробь и ее значение с пятью знаками после точки. Вычисляются отдельные члены ряда, а не сумма ряда.

### Факториал числа

В `Factorial` вычисление находится в методе `factorial()`. Используется цикл `while`: множитель уменьшается от введенного числа до `2`, а произведение накапливается в `BigInteger`.

Так, для `6` результат равен `720`. Для `0` и `1` возвращается единица, поскольку цикл не выполняется. Отрицательные значения отклоняются. `BigInteger` позволяет получить точный целочисленный результат без переполнения `int` или `long`.

## Структура программы и объекты

| Класс | За что отвечает |
| --- | --- |
| `Main` | Сумма и среднее заранее заданного массива |
| `ArrayInput` | Чтение массива, два способа подсчета суммы, минимум и максимум |
| `CommandLineArguments` | Перебор строк из `args` |
| `HarmonicSeries` | Вычисление десяти членов ряда |
| `Factorial` | Чтение числа и расчет факториала |

Основные объекты в работе: массивы, `Scanner` для ввода и значения `BigInteger`. Объекты собственных классов создавать не требуется: запуск и вычисление факториала выполняются статическими методами.

## Как запустить

Проект рассчитан на JDK 17 или новее. В IntelliJ IDEA нужно открыть папку этой работы, выбрать JDK и при необходимости отметить `src` как Sources Root. Затем запустить `main` нужного класса.

Для сборки из терминала используется `sh build.sh` в Linux или `build.bat` в Windows. Скомпилированные классы появляются в `out`.

```bash
java -cp out edu.mirea.example.Main
java -cp out edu.mirea.pr1.ArrayInput
java -cp out edu.mirea.pr1.CommandLineArguments первый второй
java -cp out edu.mirea.pr1.HarmonicSeries
java -cp out edu.mirea.pr1.Factorial
```
